# Neon Coast Studio

[![make.fun competition](https://make.fun/badges/gta6-cover-art-01.svg)](https://make.fun/competitions/gta6-cover-art-01) [![rank](https://make.fun/badges/gta6-cover-art-01/rank.svg)](https://make.fun/competitions/gta6-cover-art-01/leaderboard) [![reward](https://make.fun/badges/gta6-cover-art-01/reward.svg)](https://make.fun/competitions/gta6-cover-art-01)

Competition entry: [Brengsek27/gta6-cover-art-01-r5](https://make.fun/competitions/gta6-cover-art-01/leaderboard).

Neon Coast Studio is a local-first GTA VI cover-art editor that turns ordinary photos into vivid multi-panel stories with poster lettering, caption chips, badges, and export-ready composition. Images stay in your browser.

## Run it

1. Run `node serve.ts` with Node.js 22 or newer.
2. Open `http://localhost:8080` and load a photo or try a sample.
3. Choose a layout and colour story, then select **Export cover** to save a PNG.

Made for [make.fun](https://make.fun/).

Anton and Pacifico are bundled in `app/fonts/` under the SIL Open Font License 1.1 and loaded locally for offline use.
